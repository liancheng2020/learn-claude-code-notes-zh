Glossary

术语表

笔记里反复出现的词，先在这里对齐；解释按本教程的用法，不是教科书定义。

术语一句话解释常见误解
Agent（智能体）模型 + 一套能感知、能动手的外壳不是「会聊天的模型」，也不是工作流编排器
Harness（载具）让模型能调用工具、管理上下文、被约束的那层代码不是模型本身，也不等于框架
工具调用（tool_use）模型说「帮我执行这个」，并给出参数不是模型真的执行了代码
tool_result执行完塞回给模型的结果它属于 user 消息，不是 assistant
上下文 / 上下文窗口这次请求能带上的全部文字，有硬上限不是「记忆」，也不会自动保留
token计费和窗口的计量单位，约等于字/词片段不是字符数；中文通常更费 token
系统提示词（system）每轮都放在最前面的规则和身份说明不是用户消息，模型不能改它
hook挂在循环事件上的回调，如工具执行前后不是「插件」，也不一定异步
权限闸门工具执行前的检查：黑名单、规则、问人不是沙箱；它只挡已知模式
子 Agent（subagent）用全新上下文再跑一个循环，只返回结论不是新进程；文件、权限和父级共享
上下文压缩上下文快满时，外置/归档/截断/摘要不是删除历史；原文通常落盘
transcript压缩前保存的完整对话记录不只给人排查；模型也能按消息里的路径用 read_file 读回
外置（persist）把大结果写进文件，上下文里只留路径不是删除；按路径还能读回来
占位（placeholder）用一行 `[saved at ...]` 代替大段内容不是空值，模型可以据此去读文件
摘要（summary）让模型把历史压成事实清单会丢细节，所以放在最后一步
预算（budget）给 token / 字符数设的上限不是费用账单，但决定何时停止
幂等重复执行一次和多次，结果一样不是「加了锁」；并发下仍需锁
锁（lock）同一时间只允许一个执行者改动RLock 管线程，flock 管进程，不能互相替代
原子操作要么全做完、要么完全没发生不是「很快」，而是「不会看到中间态」
进程 / 线程进程有独立内存；线程共享内存多线程不等于多进程，锁的范围不同
worktree同一个仓库的另一个工作目录只是目录隔离，不是安全隔离
cron按时间表达式触发任务本教程是进程内轮询，退出/休眠不执行
MCP让外部服务声明并调用工具的协议本教程 s14 是内存 mock，没有真实传输
mock返回固定结果的假实现，用于离线演示不等于「简化版真实现」
runner执行一步模型的封装（mock 或真实）真实 runner 需要 client 和 model
schema对参数/输出结构的约定不是运行时校验器；本教程有轻量校验
journal每步结果的追加日志，可据此续跑不是缓存；key 不同就不会复用
注入（inject）把提醒、通知、请求塞进上下文不是修改 system prompt
